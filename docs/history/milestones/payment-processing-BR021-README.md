# Платёжный процессинг — согласование BR-02.1, комплект v0.5

**Дата:** 2026-10-09  
**Статус:** BR-01, BR-02 и BR-02.1 — согласованные бизнес-решения. Остальные проектные правила и BR-03—BR-06 — открыты.

## Что утверждено

- Длительность `PaymentIntent`: 1800 секунд по умолчанию; настраиваемый диапазон 300–86400 секунд (5 минут — 24 часа) включительно.
- Число попыток: 5 по умолчанию; диапазон 1–10 включительно.
- Настройки фиксируются при создании намерения и не меняются задним числом.
- Покупатель получает нейтральную причину блокировки; продавец — общую категорию и ссылку для обращения в поддержку; полномочные сотрудники — внутренние основания с контролем доступа.
- Истечение срока Intent блокирует новые дочерние оплаты, но **не** означает финальности уже отправленного платежа или освобождения холда.

## Что обновлено

- `payment-processing-decisions-v0.4.md` — журнал решений BR-02.1 с разделением бизнес-решений и технических предложений.
- `payment-lifecycle-spec-v0.5.md` — количественные пределы, снимок настроек, трёхуровневое отображение риска, сценарии LC-61—LC-74.
- `payment-api-v0.5.openapi.yaml` — контракт API с ограничениями и предложенным ресурсом настроек продавца `/v1/payment_intent_settings` (GET/PATCH), категориями риска и ссылкой поддержки. Адрес настройки — проектное решение.
- `payment-processing-architecture-v0.4.md` — границы ответственности, риск-данные, неизменность настроек.
