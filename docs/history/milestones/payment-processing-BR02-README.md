# Платёжный процессинг — фиксация BR-02, пакет v0.4

**Дата:** 2026-10-09  
**Статус:** BR-01 и BR-02 согласованы заказчиком. BR-03—BR-06 открыты. Числовые значения лимитов и сроков BR-02 НЕ согласованы.

## Содержимое

- `payment-processing-decisions-v0.3.md` — журнал решений; точная формулировка BR-02 с разграничением требований и проектных дополнений.
- `payment-lifecycle-spec-v0.4.md` — жизненный цикл Payment и PaymentIntent, триггеры закрытия, случаи активных/неизвестных банковских операций, дополнительные сценарии LC-49—LC-60.

- `acquirer-connector-contract-tests-v0.3.yaml` — 97 сценариев (включая 20 новых BR-02), **не запускались**.
- `acquirer-connector-v0.2.ts` — прежний типизированный контракт соединителя, не изменён по BR-02, поскольку политикой намерений владеет ядро.
- `tkb-connector-profile-v0.2.yaml` — прежний профиль ТКБ; BR-02 не является договорным подтверждением банка.

## Согласовано

1. Новые Payment внутри Intent прекращаются по истечении окна, достижении лимита, отмене продавца или блокировке рисков.
2. Отказ конкретного дочернего Payment сам по себе не завершает Intent, если остальные ограничения допускают новый платёж.
3. Неуспешный финальный статус Intent только после исключения незавершённого финансового эффекта.
4. Ранее начатый банковский платеж может завершиться после закрытия окна новых попыток; подтверждённое списание нельзя отвергать.
5. Действующий холд не отменяется таймером новых попыток.
