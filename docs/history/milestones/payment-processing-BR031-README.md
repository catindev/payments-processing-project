# Согласование BR-03.1 — обновлённые спецификации v0.6

**Дата:** 2026-10-09  
**Статус:** BR-03.1 утверждено заказчиком; BR-03.2 открыто.

## Что согласовано

- Один успешный окончательный `capture` на один холд в первом выпуске — на полную или частичную сумму.
- Поддержка нескольких успешных `capture` по одному холду остаётся расширением и в v1 выключена.

## Что осталось предложением аналитика / банковской зависимостью

- В первом выпуске публичный параметр `final_capture` только `true` (либо отсутствует); `false` возвращает отказ до банка.
- Доказанно отклонённую без финансового эффекта команду разрешается повторно выполнить новой командой при действующем холде — это не второй успешный `capture`.
- Освобождение остатка частичного холда нельзя предполагать без подтверждённой семантики банка.
- Документы ТКБ содержат вызов `/api/v1/card/unregistered/hold/confirm/partial`, но это не подтверждает доступность функциональности у тестового терминала и не гарантирует повторность/окончательность.
- BR-03.2: какая сумма делает `PaymentIntent` полностью оплаченным и какое состояние должно отражать частичную оплату заказа — **не согласовано**.
