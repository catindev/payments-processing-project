# BR-06 — денежные поля. Комплект v0.10

Дата: 2026-10-09  
Статус бизнес-решений: **BR-01, BR-02, BR-02.1, BR-03.1, BR-03.2, BR-04, BR-05, BR-06, NAME-01 согласованы**.  
Статус API: **черновик**, не опубликован и не подтверждён банковскими испытаниями.

## Согласованное BR-06

- При создании `Payment`/`PaymentIntent`: `amount` (целое количество копеек), `currency: RUB`.
- В ответе отдельного `Payment`: `currency: RUB`, `amounts` со всеми денежными показателями; вложенных `{value,currency}` у каждой суммы нет.
- В ответе `PaymentIntent`: `currency: RUB`, `amounts: {requested, final, paid}`. `final=null`, пока не подтверждено окончательное списание; после `succeeded` `final=paid`. Это **техническая унификация** уже согласованной BR-03.2, а не новая политика изменения стоимости покупки. Первоначальный `requested` неизменен.
- В `Refund` и `PaymentOperation` с **одной** суммой: `amount` и `currency` в ресурсе; `currency` наследуется от Payment.
- Первая версия — RUB, целые копейки. Нет валютной конвертации, float и округлений; суммы комиссий и перечислений продавцам отдельно.
- Во внутренних хранилищах допускаются отдельные типизированные целочисленные колонки; `amounts` — структура публичного ответа, а не требование хранить деньги в JSONB/BSON.
