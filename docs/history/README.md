# Исторические версии

В этом каталоге сохранены ранние документы, изменения API и проверки, выпущенные на этапах BR-01—BR-07. Здесь **не** действующие требования.

Актуальные решения и схемы лежат в `../current/`. Некоторые исторические документы содержат отменённые идеи (`PaymentAttempt`, прежние суммы, приоритет hosted checkout) и устаревшие ссылки. Применять только для исследования причин решений и сравнения версий.

Исторический профиль ТКБ с совпадающим именем, но отличающимся содержимым, сохранён с хеш-суффиксом, чтобы не затереть данные.
