# Актуальный срез

**Самая поздняя редакция документов из предыдущего обсуждения.** Не все детали реализованы и проверены. Версии файлов не совпадают, потому что каждую спецификацию обновляли независимо.

`payment-processing-decisions-v1.1.md` — источник согласованных решений. `payment-checkout-design-v0.2.md` уточняет обязательный BR-07. Остальное — разработанные проекты, подлежащие проверке агентом.
