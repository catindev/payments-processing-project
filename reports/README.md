# Отчёты и доказательства (пока отсутствуют)

Здесь находятся **реальные результаты** локального агента, отделённые от исходных описательных сценариев.

- `templates/experiment.md` — отчёт об отдельном эксперименте.
- `results/tkb/` — банковские разрешённые test-only эксперименты.
- `results/simulator/` — исполнение сценариев без доступа к банку.
- `results/audit/` — найденные противоречия и документы с ревью.
- `raw/` — НЕ коммитить. Здесь только локальные приватные необработанные логи; лучше вообще не сохранять PAN/CVV.

Не придумывать успешные результаты и не переименовывать NOT_RUN в PASS на основании документации. Каждый результат требует фактической команды и очищенного доказательства. Прежде чем публиковать, проверить отсутствие учётных данных и банковских идентификаторов, раскрывающих клиентов.
